Quick Start Guide

Run these terminal commands to set up dependencies, build the workspace, deploy to Google Cloud, and start testing.

01

Prerequisites & Environment

Ensure Python 3.10+ and uv are installed. Install the agents CLI global utility and run the automated setup:

terminal (bash) 
# Install Google Agents CLI globally
uv tool install google-agents-cli

# Perform automated SDK setup
uvx google-agents-cli setup

# Verify installation versions
agents-cli --version
02

Clone & Install Project

Navigate to the repository folder, lock environment packages, and run local installation scripts:

terminal (bash) 
# Navigate to project root
cd trip-planner/

# Install defined Python dependencies 
agents-cli install

# Activate the local virtual environment
source .venv/bin/activate
03

Build with AGY CLI

Generate Python sub-agents, orchestrators, and tool scripts autonomously using agy CLI:

terminal (bash) 
# Launch the autonomous development assistant
agy --dangerously-skip-permissions

# (Inside AGY CLI console)
# /goal Build a multi-agent Road Trip Planner application in Python...
04

Deploy to Agent Engine (GEAP)

Scaffold the production GCP container layout and ship the reasoning engine directly to Vertex AI:

terminal (bash) 
# Authenticate Application Default Credentials
gcloud auth application-default login

# Scaffold deployment configurations
agents-cli scaffold enhance . --region us-central1

# Deploy reasoning engine to Agent Engine on Google Cloud
agents-cli deploy --project YOUR_PROJECT_ID --region us-central1
05

Run Local Web Dashboard

Start your local interactive frontend to plan driving legs, view streaming chats, and trace logs:

terminal (bash) 
# Start local Python server
python3 server_cloudrun.py

# open local browser link
# http://localhost:8080

Google Cloud Integration

The solution incorporates enterprise cloud capabilities, utilizing Vertex AI reasoning frameworks alongside traditional Google APIs.

🧠

Vertex AI

Powers our model orchestration. Runs Gemini 2.5 Flash for advanced structured output parsing and control-transfer decision trees.

☁️

Agent Engine (GEAP)

Acts as the serverless host runtime. Automatically handles scaling, manages API routes, and manages state database keys.

Google Maps API

Used by the route_planner. Generates route waypoints, coordinates path legs, and calculates travel times.

Queried by the hotel_agent and activities_agent. Looks up verified lodgings, restaurants, and sights with real-time ratings.

Hosts our static web client and gateway server. Fully managed serverless container scaling with instant page loading.

🔒

Identity-Aware Proxy

Restricts deployment access to authenticated enterprise users. Secures the sales demo gateway against unauthorized usage.
